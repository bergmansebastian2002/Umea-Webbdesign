# Bildrättigheter - Restaurang Shanghai

Hero och logotyp är hämtade 2026-09-11 från kundens egen webbplats
restaurangshanghai.se, för användning på kundens nya webbplats. Bekräfta med
kunden vid överlämningen att bilderna får återanvändas (gamla sajten är byggd
i Net3DG - be kunden intyga att de äger materialet).

Övriga bilder är PLATSHÅLLARE från Unsplash tills kunden fotograferat egna
motiv (se FOTOLISTA.md). De omfattas av
[Unsplash-licensen](https://unsplash.com/license): fri kommersiell användning
utan attribution. Foto-id gör att bilden kan återfinnas på
`https://unsplash.com/photos/<id>`.

Medvetet BORTVALDA källor:
- Gamla sajtens `img_meny_02.jpg` och `img_buffe.jpg` - endast 235x180 px,
  för låg upplösning för den nya sajten.
- TripAdvisor-foton (interiör med tegel, mörka trästolar och etsade
  glasspeglar) - användaruppladdade och upphovsrättsskyddade. Användes bara
  som research; kundens egna nytagna foton ska ersätta platshållarna.

OBS: `om-oss.jpg` föreställer INTE Shanghais matsal - den måste bytas mot ett
riktigt foto före lansering, eller godkännas uttryckligen av kunden som
tillfällig platshållare.

Nytagna foton ersätter platshållarna enligt `FOTOLISTA.md` - byt fil, kör
`npm run bilder -- shanghai` och uppdatera alt-text + denna tabell.
