# Bildrättigheter - Lotus asiatiska restaurang

Kunden har ingen tidigare webbplats och inga högupplösta egna foton har
samlats in ännu - SAMTLIGA bilder är platshållare från Unsplash tills kunden
fotograferat egna motiv (se FOTOLISTA.md). De omfattas av
[Unsplash-licensen](https://unsplash.com/license): fri kommersiell användning
utan attribution. Foto-id gör att bilden kan återfinnas på
`https://unsplash.com/photos/<id>`.

Medvetet BORTVALDA källor:
- Facebook-sidans profil- och omslagsbild (röd lotus-logotyp) - för låg
  upplösning för webben och kundens egendom; be kunden om originalfilen
  (vektor/hög upplösning) vid överlämningen. Användes endast som research
  för färgpaletten.
- Facebook-sidans rosa menykort och matfoton - kundens egna original bör
  hämtas direkt från kunden, inte skrapas från Facebook.
- foodoras produktbilder - foodoras/fotografens material, inte fritt att
  återanvända.

Nytagna foton ersätter platshållarna enligt `FOTOLISTA.md` - byt fil, kör
`npm run bilder -- lotus` och uppdatera alt-text + denna tabell.
