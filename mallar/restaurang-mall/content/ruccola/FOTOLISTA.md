# Fotolista - Ristorante Ruccola

Bilder att be kunden om (eller fotografera på plats) för att ersätta
platshållarna. Liggande format om inget annat anges, dagsljus eller varmt
restaurangljus, utan blixt.

| Prio | Motiv | Ersätter | Tips |
|---|---|---|---|
| 1 | Nygräddad signaturpizza (t.ex. Nali eller Salsiccia) snett ovanifrån | hero-margherita | Minst 1920 px bred. Leopardfläckarna på kanten ska synas - det är surdegsbeviset. |
| 2 | Pizzabagaren vid ugnen eller degen som sträcks | om-oss-surdeg | Människor + hantverk säljer "om oss" bäst. |
| 3 | Pizza med ruccola/burrata rakt ovanifrån | galleri/pizza-ruccola-burrata | Stående format funkar - bilden får dubbel höjd i galleriet. |
| 4 | Carbonara eller oxfilépasta i djup tallrik | galleri/pasta-carbonara | Riv ost över precis före bilden. |
| 5 | Caesarsallad | galleri/sallad-caesar | Gärna med synlig kyckling/räkor. |
| 6 | Matsalen eller fasaden på Östra Kyrkogatan | galleri/pizza-rustik | Visar att det är en riktig kvarterskrog på Haga. |
| 7 | Höstpizzan eller annan säsongspizza | galleri/pasta-penne | Byt per säsong - bra Instagram-material samtidigt. |

Instagram @ruccolaumea har redan bra material - be om originalfilerna
(appen komprimerar hårt) och ok att använda dem på sajten.

Efter byte: NYTT filnamn (aldrig samma - bildcachen), kör
`npm run bilder -- ruccola`, uppdatera alt-texter i config.ts och tabellen i
BILDRATTIGHETER.md.
