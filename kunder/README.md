# Kundsajter

En mapp per kund, kopierad från `../mallar/restaurang-mall`.

```bash
cp -r ../mallar/restaurang-mall ./<kundnamn>
```

Följ checklistan i `../mallar/restaurang-mall/docs/NY-KUND.md`.

När kundsajten ska publiceras: skapa ett eget GitHub-repo för kunden och
koppla det till Vercel - då får varje kund egna deployer och egen domän.
